# Журнал изменений

Записи добавляются командой `./book.sh release`.
Каждую запись пишет автор — не скрипт.

---

## v0.2.1 — 2026-08-27

Механическая защита канона стиля — второй слой из `docs/integration-roadmap.md` §9.4.

**Добавлено**
- `scripts/style-lint.py` — линтер канона: адресация не по канону («ты», авторское
  «я»), аббревиатуры предметной области в прозе, ссылки «см. §» вместо краткого
  повтора, канцелярит, шаблонные зачины, пустые усиления, эмодзи, тяжёлое
  форматирование, первое лицо единственного числа («я», «меня», «мой»).
  Правила разделены по группам канона: канцелярит и шаблонные зачины — ошибка,
  пустые усиления — предупреждение, потому что зависят от контекста.
- Серьёзность каждого правила настраивается в `metadata.yaml` (`style_lint.severity`),
  вплоть до `off` — книга может узаконить своё отклонение от канона.

**Изменено**
- `book.sh` — команда `./book.sh lint [пути]` и пункт в интерактивном меню.
- `book.sh` — новый статус параграфа **`todo`**: скелет размечен, текста нет.
  Своя иконка в `status`, пометка «(скелет)» в оглавлении, попадание в сборку
  только по фильтру `all`. Книга со скелетами больше не выглядит книгой с
  черновиками.
- Оба workflow — гейт стиля перед сборкой; в ночной он не блокирующий,
  потому что она собирает черновики.

**Исправлено**
- Сборка сайта больше не копирует весь репозиторий в `book/`. При `src = "."`
  mdBook переносит в каталог вывода всё содержимое источника — включая `.git`,
  `.env`, `dist/` и `spec/`. Теперь сайт собирается из временного каталога, куда
  кладутся только `SUMMARY.md`, `README.md`, `chapters/`, `theme/` и `assets/`.
  По двенадцати книгам это 80 МБ → 39 МБ и никаких ключей API в выводе, который
  уходит на Pages. (Утечки в продакшене не было: CI собирает из чекаута, где
  `.env` отсечён `.gitignore`.)

**Удалено**
- Файл `VERSION` в книгах. Его не читал ни `book.sh`, ни один workflow: версия
  книги живёт в `metadata.yaml`, версию шаблона отслеживает `template_version`.
  Второй источник правды уже успел разъехаться с первым. `VERSION` остаётся
  только в самом шаблоне, где обозначает его собственную версию.

**Что линтер намеренно не считает нарушением**
- Содержимое кавычек-ёлочек, в том числе многострочное: имена объектов, прямые
  цитаты дерева метаданных, речь персонажей.
- Реплики диалога, начинающиеся с тире.
- Синтаксис платформы: `РН.Остатки`, `РС.СрезПоследних`.
- Числовые окончания: «10%-я скидка», «2-я форма».
- Границы слова учитывают кириллицу: «неочевидно» не ловится на «очевидно».
- Нумерованную прозу. Правило «не более четверти разметки» возражает против
  дробления мысли на короткие пункты, а не против нумерации: пункт списка
  длиной в абзац (от 200 знаков) считается прозой и в метрику не идёт.

Честная граница: линтер ловит дёшево и грубо. Перегрузку терминов, сломанные
метафоры и ощущение голоса по-прежнему судят панель ревью и человек.

## v0.2.0 — 2026-08-27

Панель ревью, штамп сборки, заготовка печатного контура.

**Добавлено**
- `scripts/review.py` — мультимодельная панель ревью, `scripts/status.sh` — прогресс по главам.
- `scripts/prompts/` — шесть промптов ревьюеров (структура, стиль, тон, метафоры, факты, адвокат дьявола).
- `docs/review-workflow.md`, `.env.example`, `.gitignore`.

**Изменено**
- `book.sh` — штамп сборки (build-info) и `theme/version.js`; опциональный `-H assets/print/header.tex` для колонтитулов PDF.
- `theme/book-extra.css` — callout-блоки, иерархия заголовков, стили печати страницы.
- `.github/workflows/build-{release,nightly}.yml` — `texlive-latex-extra` (нужен для колонтитулов).
- `book.sh` — заголовки в `SUMMARY.md` и в `./book.sh status` берутся из `# `, иначе из
  первого `## ` (по конвенции H1 только у первого файла модуля) — вместо транслита имени
  файла; название модуля в оглавлении — из `# Модуль N. …`; обрезка длинных заголовков
  считает символы, а не байты, поэтому кириллица больше не рвётся посреди буквы.
- `docs/style-guide.md` — единый канон стиля серии.

Печатное издание и runnable-листинги вынесены в v0.3.0 / v0.4.0 — см. `docs/handoff-v0.3-print/`.
