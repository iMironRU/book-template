# Журнал изменений

Записи добавляются командой `./book.sh release`.
Каждую запись пишет автор — не скрипт.

---

## v0.7.0 — 2026-09-13

Пометки перестали протекать к читателю, а места для снимков стали видимыми.

**Исправлено**
- `scripts/style-lint.py`, правило `comment` — пустая строка нужна теперь с
  **обеих** сторон комментария. Раньше проверялась только строка после, и
  комментарий, прилипший снизу к таблице, markdown считал её продолжением:
  pandoc печатал читателю «<!-- FIXME стенд: … -->» прямо в тексте EPUB.
  В книге о формах так протекали все 66 пометок.

**Добавлено**
- `scripts/shot-slots.py` — пометка `<!-- СКРИН: что снять -->` превращается
  на сборке в скелет снимка: полоса заголовка, панель инструментов, колонка
  дерева и поля справа, под ним подпись, что здесь будет. Читатель черновика
  видит, что картинка не забыта, а ещё не сделана. Правятся копии, исходники
  не трогаются: для сайта — временный каталог сборки, для форматов —
  `.build-src`, который убирается за собой.
- Скелет одинаково собран для сайта и для EPUB: разметка без флексов и сеток —
  часть читалок раскладывает их по-своему.

**Изменено**
- `book.sh` — шаг заглушек в обеих сборках.
- `theme/site-bslexicon.css`, `assets/print/epub.css` — оформление скелета.

## v0.6.1 — 2026-09-13

Починки по следам обкатки на всех книгах серии.

**Исправлено**
- `scripts/search-index.py` — в индекс не попадал текст до первого подзаголовка,
  то есть «Открытие» каждого параграфа, а в книгах без подзаголовков — весь
  параграф целиком. У «1С-разговорника» это было три четверти книги.
- `scripts/og-image.py` — строка о книге бралась из README как есть: в карточку
  попадали картинки, разметка и текст самого шаблона у книг, чей README ещё не
  переписан. Теперь берётся только текст, а шаблонный README не считается
  рассказом о книге. Строка серии печатается, только если книга и правда
  в серии (`series` в `metadata.yaml`).

## v0.6.0 — 2026-09-13

Ссылка на книгу перестала быть голым адресом; внутри параграфа появилась
навигация.

**Добавлено**
- `scripts/site-meta.py` — описание страницы, Open Graph, канонический адрес.
  mdBook оставлял описание пустым, и книга, посланная ссылкой в мессенджер,
  выглядела адресом без картинки и без строчки о чём она. Описание берётся из
  первого абзаца страницы, заголовок — из `<title>` без значка статуса.
  Заодно `theme-color` перекрашен из белого в цвет сайта: на телефоне он красит
  адресную строку.
- `scripts/og-image.py` — карточка ссылки 1200×630 в оформлении обложки серии.
  Обложка книги вертикальная, в широкую карточку она не встаёт. Строка о книге
  берётся из цитаты под названием в README. Рисуется локально (нужен Chrome),
  файл `assets/img/og.png` коммитится.
- `theme/page-nav.js` — оглавление разделов параграфа и кнопка «наверх».
  На широком экране оглавление стоит справа и подсвечивает раздел, который
  читатель видит сейчас; на узком — свёрнутой строкой под заголовком.

**Изменено**
- `book.sh` — мета-теги дописываются после сборки сайта, вместе с индексом.
- `theme/site-bslexicon.css` — оформление оглавления, кнопки «наверх» и
  правило печати: ни оглавление, ни кнопки на бумагу не идут.

## v0.5.0 — 2026-09-13

Поиск по книге, который понимает русский.

**Добавлено**
- `scripts/search-index.py` — свой поисковый индекс. Родной поиск mdBook
  русского текста не видел вовсе: индекс собирается английским конвейером
  elasticlunr, кириллица отбрасывается ещё на сборке, и в готовом
  `searchindex.json` не было ни одного русского слова — запрос «форма» в книге
  о формах давал ноль. Единица поиска — раздел параграфа, а не страница:
  читатель ищет «быстрый выбор» и попадает в место. Основы слов считает
  алгоритм Портера для русского; клиенту уезжает словарь «слово → основа».
- `theme/search-ru.js` — своя оболочка поиска: панель по кнопке в шапке или
  по «/», выдача с хлебными крошками и подсвеченной цитатой, стрелки и Enter
  с клавиатуры. Перейдя из выдачи, читатель видит искомое подсвеченным прямо
  в тексте; Esc снимает подсветку. Указатель грузится при первом открытии
  поиска, не раньше.

**Изменено**
- `book.toml` — родной поиск отключён (`search.enable = false`): он не только
  бесполезен на русском, но и тянул лишний индекс.
- `book.sh` — индекс собирается сразу после mdBook, в том числе на сборочной
  машине.
- `theme/site-bslexicon.css` — оформление панели поиска и подсветки.

## v0.4.0 — 2026-09-13

Сайт книги перестал быть отпечатком бумаги: ответы раскрываются под вопросом,
меню закрывается пальцем.

**Добавлено**
- `theme/answers.js` — ответы под контрольными вопросами и упражнениями.
  Кнопка держит бумажный порядок: сначала указание, потом ответ, потом «Скрыть».
  Текст берётся со страницы ответов главы, так что источник остаётся один —
  файл `NN-99_otvety.md`. Разбирает обе принятые в серии записи ответа
  («К вопросу 1» и «Вопрос 1»), упражнение длиной в несколько абзацев получает
  кнопку в конце, после кода и ссылок. Строка «Ответы — в конце части»
  на сайте заменяется ссылкой на полную страницу ответов.
- `theme/sidebar-tap.js` — на узком экране тап по тексту закрывает боковое меню:
  промах по кнопке больше не оставляет читателя в оглавлении.

**Изменено**
- `theme/site-bslexicon.css` — иконки в шапке 22 пикселя вместо 16: рядом с
  названием книги прежние терялись. Селекторы шапки переведены с идентификаторов
  на классы: в свежем mdBook идентификаторы получили приставку `mdbook-`,
  и правила по `#menu-bar` молча переставали работать.
- `book.toml` — оба сценария подключены в `additional-js`.

## v0.2.1 — 2026-08-27

Механическая защита канона стиля — второй слой из `docs/integration-roadmap.md` §9.4.

**Добавлено**
- `scripts/style-lint.py` — линтер канона: адресация не по канону («ты», авторское
  «я»), аббревиатуры предметной области в прозе, ссылки «см. §» вместо краткого
  повтора, канцелярит, шаблонные зачины, пустые усиления, эмодзи, тяжёлое
  форматирование, первое лицо единственного числа («я», «меня», «мой»).
  Правила разделены по группам канона: канцелярит и шаблонные зачины — ошибка,
  пустые усиления — предупреждение, потому что зависят от контекста.
- Серьёзность каждого правила настраивается в `metadata.yaml` (`style_lint.severity`),
  вплоть до `off` — книга может узаконить своё отклонение от канона.

**Изменено**
- `book.sh` — команда `./book.sh lint [пути]` и пункт в интерактивном меню.
- `book.sh` — новый статус параграфа **`todo`**: скелет размечен, текста нет.
  Своя иконка в `status`, пометка «(скелет)» в оглавлении, попадание в сборку
  только по фильтру `all`. Книга со скелетами больше не выглядит книгой с
  черновиками.
- Оба workflow — гейт стиля перед сборкой; в ночной он не блокирующий,
  потому что она собирает черновики.

**Исправлено**
- Сборка сайта больше не копирует весь репозиторий в `book/`. При `src = "."`
  mdBook переносит в каталог вывода всё содержимое источника — включая `.git`,
  `.env`, `dist/` и `spec/`. Теперь сайт собирается из временного каталога, куда
  кладутся только `SUMMARY.md`, `README.md`, `chapters/`, `theme/` и `assets/`.
  По двенадцати книгам это 80 МБ → 39 МБ и никаких ключей API в выводе, который
  уходит на Pages. (Утечки в продакшене не было: CI собирает из чекаута, где
  `.env` отсечён `.gitignore`.)

**Удалено**
- Файл `VERSION` в книгах. Его не читал ни `book.sh`, ни один workflow: версия
  книги живёт в `metadata.yaml`, версию шаблона отслеживает `template_version`.
  Второй источник правды уже успел разъехаться с первым. `VERSION` остаётся
  только в самом шаблоне, где обозначает его собственную версию.

**Что линтер намеренно не считает нарушением**
- Содержимое кавычек-ёлочек, в том числе многострочное: имена объектов, прямые
  цитаты дерева метаданных, речь персонажей.
- Реплики диалога, начинающиеся с тире.
- Синтаксис платформы: `РН.Остатки`, `РС.СрезПоследних`.
- Числовые окончания: «10%-я скидка», «2-я форма».
- Границы слова учитывают кириллицу: «неочевидно» не ловится на «очевидно».
- Нумерованную прозу. Правило «не более четверти разметки» возражает против
  дробления мысли на короткие пункты, а не против нумерации: пункт списка
  длиной в абзац (от 200 знаков) считается прозой и в метрику не идёт.

Честная граница: линтер ловит дёшево и грубо. Перегрузку терминов, сломанные
метафоры и ощущение голоса по-прежнему судят панель ревью и человек.

## v0.2.0 — 2026-08-27

Панель ревью, штамп сборки, заготовка печатного контура.

**Добавлено**
- `scripts/review.py` — мультимодельная панель ревью, `scripts/status.sh` — прогресс по главам.
- `scripts/prompts/` — шесть промптов ревьюеров (структура, стиль, тон, метафоры, факты, адвокат дьявола).
- `docs/review-workflow.md`, `.env.example`, `.gitignore`.

**Изменено**
- `book.sh` — штамп сборки (build-info) и `theme/version.js`; опциональный `-H assets/print/header.tex` для колонтитулов PDF.
- `theme/book-extra.css` — callout-блоки, иерархия заголовков, стили печати страницы.
- `.github/workflows/build-{release,nightly}.yml` — `texlive-latex-extra` (нужен для колонтитулов).
- `book.sh` — заголовки в `SUMMARY.md` и в `./book.sh status` берутся из `# `, иначе из
  первого `## ` (по конвенции H1 только у первого файла модуля) — вместо транслита имени
  файла; название модуля в оглавлении — из `# Модуль N. …`; обрезка длинных заголовков
  считает символы, а не байты, поэтому кириллица больше не рвётся посреди буквы.
- `docs/style-guide.md` — единый канон стиля серии.

Печатное издание и runnable-листинги вынесены в v0.3.0 / v0.4.0 — см. `docs/handoff-v0.3-print/`.
