# /template-spec-review

Сделать обзорный проход по спецификации шаблона:
`spec/constitution.md`, `spec/specification.md`,
`spec/print-edition.md`.

## Что делает команда

1. Читает все spec-файлы
2. Проверяет внутреннюю согласованность:
   - Конституции между собой не противоречат
   - Спецификация не выходит за рамки конституций
   - Принципы декларированные в одном месте поддерживаются в других
3. Проверяет, что текущая реализация (theme, filters, docs)
   соответствует спецификации
4. Идентифицирует gap'ы:
   - Что в spec, но не реализовано
   - Что реализовано, но не задокументировано в spec
5. Выводит сводку и список рекомендаций

## Использование

```
/template-spec-review
```

## Вывод

Структурированный отчёт:

### Согласованность спецификаций

- ✓ / ✗ для каждой пары документов

### Покрытие реализацией

- Для каждого пункта spec — наличие в коде/тестах
- Для каждого файла реализации — наличие в spec

### Рекомендации

- Список задач к добавлению в текущий или следующий спринт
- Приоритизированный (critical / important / nice-to-have)

## Когда запускать

- Перед началом каждого спринта
- После закрытия спринта (контрольная сверка)
- Перед релизом новой версии шаблона
- При обновлении любого spec-документа
