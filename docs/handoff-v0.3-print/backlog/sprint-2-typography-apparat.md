# Спринт 2 — русская типографика и аппарат учебника

**Цель.** Сделать русский набор технически правильным и
довести аппарат печатной книги до издательского стандарта.

После этого спринта печатная версия становится полностью
готовой к подаче в типографию.

## Состав работ

### 2.1 Препроцессор русской типографики

- [ ] Создать `theme/filters/russian-typo.py` — pandoc-filter
  на python, применяемый перед сборкой
- [ ] Что делает (по приоритету):
  1. **«Ёлочки» вместо `"..."`**: `"текст"` → `«текст»`,
     внутри `"text"` → `„text"` (вложенные)
  2. **Висячие предлоги** через неразрывный пробел: после
     `в, на, по, с, у, к, о, об, обо, и, а, но, да, же, ли,
     бы, же, не` ставится `\u00A0` (или `~` в LaTeX-выходе)
  3. **Разряды чисел**: `100000` → `100\,000` (только вне
     блоков кода и URL)
  4. **Тире**: `--` → `—` (em-dash), пробелы вокруг тире
     обрабатываются
  5. **Многоточие**: `...` → `…` (один символ)
  6. **Сокращения**: «т.~е.», «т.~к.», «и~т.~д.», «и~т.~п.»,
     «г.~Москва», «ул.~Иванова»
  7. **Инициалы**: `А. С. Пушкин` → `А.\,С.\,Пушкин`
- [ ] Filter работает над AST, не над сырым Markdown —
  не трогает блоки `Code` и `CodeBlock`, не трогает `Link.target`
- [ ] Включается опцией `typography: russian` в `metadata.yaml`
  (default `true` для русских книг)
- [ ] Подключается ко **всем** форматам, не только PDF
  (ёлочки нужны и в EPUB, и в HTML)

### 2.2 Титульный лист и оборот титула

- [ ] Создать `theme/partials/title-page.tex`:
  - Сверху — `subseries` (например, «Школа 1С-инженеров. Книга 1»)
  - Большими буквами — `title`
  - Меньше — `subtitle`
  - Внизу — автор, год, город
- [ ] Создать `theme/partials/title-verso.tex` (оборот):
  - УДК, ББК, авторский знак
  - Аннотация
  - ISBN
  - Знак копирайта или лицензия (CC BY 4.0)
  - Информация о шаблоне (template version)
- [ ] Расширить `metadata.yaml`:
  ```yaml
  publication:
    subseries: "Школа 1С-инженеров. Книга 1"
    udk: "004.4"
    bbk: "32.973"
    isbn:
      print: "978-5-..."
      epub: "978-5-..."
    annotation: |
      Краткая аннотация для оборота титула в 4-6 строк.
    city: "Москва"
    year: 2026
    publisher: ""        # пусто если самиздат
  ```
- [ ] Подключить partials через `$include-before$` или
  условный блок в template

### 2.3 Шмуцтитулы частей

- [ ] Если в книге есть `\part{...}` (модули в нашем случае),
  каждая часть начинается с шмуцтитула — нечётной правой
  страницы с названием по центру, оборотная сторона чистая
- [ ] Реализовать через memoir `\partstyle` или кастомный
  `\renewcommand{\partformat}{...}`

### 2.4 Выпускные данные

- [ ] Создать `theme/partials/colophon.tex` для последней
  нечётной страницы:
  - Учебное / научное / справочное издание
  - Автор полностью
  - Название
  - Технический редактор (если есть)
  - Корректор (если есть)
  - Подписано в печать (дата релиза)
  - Формат, бумага, гарнитура
  - Печ. л., тираж
  - Типография

### 2.5 Предметный указатель

- [ ] Подключить `imakeidx` в template
- [ ] В Markdown разметка через pandoc-attribute:
  ```markdown
  Запрос [\index{запрос}]{} начинается с ключевого слова...
  ```
  Или через свой filter, превращающий ` ::: index ... ::: ` в `\index{}`
- [ ] Стилизация индекса: двухколоночный вёрстка, мелкий кегль
- [ ] Выводится в `\backmatter`

### 2.6 Список листингов и список рисунков

- [ ] Авто-генерация через memoir `\listoffigures` и `\listoflistings`
- [ ] Включается опцией `lof: true` и `lol: true` в `metadata.yaml`
- [ ] Размещается после оглавления

## Acceptance criteria

1. Препроцессор:
   - На тестовых строках выполняются все замены
   - В блоках кода ничего не трогается (`СУММА(...)` остаётся как было)
   - URL не повреждаются
   - Работает и для EPUB, и для PDF (ёлочки появляются везде)

2. Аппарат:
   - PDF начинается с титула на нечётной правой странице
   - Оборот титула содержит УДК/ББК/ISBN/копирайт
   - Каждая часть начинается со шмуцтитула
   - Книга заканчивается выпускными данными
   - Предметный указатель собирается без ошибок

3. На двух готовых книгах «1С как иностранный язык»:
   - Pre-press проверка типографии формально проходит
   - Список листингов и рисунков заполнен корректно

## Out of scope

- Список литературы (biblatex) — отдельный спринт по необходимости
- Именной указатель — пока не делаем, добавим если потребуется
- Глоссарий — рассматривается в Спринте 5 как опция

## Риски

- Висячие предлоги через словарь — могут быть false positive
  (например, «не» как частица vs «не» как местоимение). Подход:
  применяем только к коротким предлогам и союзам, не трогаем
  частицы; allowlist должен пересматриваться.
- Разряды чисел в коде — самая частая ошибка препроцессоров.
  Решение: смотреть на AST, не на текст.
- ISBN на печать и EPUB — формально разные, нужно подтвердить
  у получающего органа (РКП или сервис).
