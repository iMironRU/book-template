# Pre-press: спецификация подготовки PDF к типографии

Этот документ описывает технические требования к PDF,
который отправляется в офсетную типографию для малотиражной
ч/б печати.

## Базовые параметры формата

| Параметр | Значение |
| --- | --- |
| Формат после обрезки | A5 (148 × 210 мм) |
| Размер до обрезки (с бликом) | 154 × 216 мм (при bleed 3 мм) |
| Без блика | 148 × 210 мм |
| Ориентация | портретная |
| Полей кратно | 1 мм (типографии так удобнее) |

## Поля под тип переплёта

Внутреннее поле (gutter) — это поле у корешка. Зависит от типа переплёта:

| Переплёт | Gutter | Когда применять |
| --- | --- | --- |
| **КБС (клеевой бесшвейный)** | 20–22 мм | До 5000 экз. — самый распространённый |
| **Шитьё нитками** | 16–18 мм | Премиум, >5000 экз., раскрывается ровно |
| **Скоба** | 12–14 мм | Тонкие книги (до 64 стр.) |

В нашем дефолте: КБС, gutter 20 мм.

Внешнее поле, верхнее, нижнее — по эстетике, типично:
14–16 мм / 16–18 мм / 18–22 мм. Нижнее обычно больше верхнего —
оптический центр выше геометрического.

## Цветовое пространство

| Параметр | Значение |
| --- | --- |
| Pure colorspace | **DeviceGray** (один канал K) |
| Не использовать | RGB, CMYK, Lab, sRGB→Gray-конверсия внутри PDF |
| ICC-профиль | Coated FOGRA39 или согласованный с типографией |
| Чёрный текст | 100% K (никакого rich black) |
| Заливки и подложки | 10–80% K (вне этого диапазона — потеря деталей) |
| Тонкие линии | минимум 0.25 pt (~0.09 мм); тоньше типография «теряет» |

## PDF-стандарт

| Параметр | Значение |
| --- | --- |
| Версия PDF | 1.4 или 1.6 |
| Соответствие | **PDF/X-1a:2001** (или X-3:2003 если разрешает типография) |
| Embed шрифтов | Все subset-embedded |
| Прозрачности | Запрещены (должны быть flatten'ed) |
| Слои (OCG) | Запрещены |
| Кодировка | Unicode (UTF-8) для metadata |

Валидация: `verapdf --flavour 1a` без ошибок.

## Метки реза и блик

| Параметр | Значение |
| --- | --- |
| Crop marks | Ставит типография; в нашем PDF не нужны |
| Bleed | 3 мм если есть заливки/картинки к краю; 0 мм если нет |
| Trim box | Точно совпадает с форматом 148×210 мм |
| Media box | Trim + bleed по всем сторонам |

## Растровые элементы

| Параметр | Значение |
| --- | --- |
| Разрешение фото / скриншотов | 300 dpi @ финальном размере (минимум) |
| Разрешение line-art (вектор-в-растр) | 600 dpi |
| Сжатие | JPEG q=85 для фото; ZIP для line-art |
| Цветовое пространство | Grayscale, не RGB |
| Контраст | Поднять +10–15% перед вставкой (офсет «съедает») |
| Резкость | Лёгкий sharpen после grayscale-конверсии |

## Векторные элементы

| Параметр | Значение |
| --- | --- |
| Источник | TikZ (предпочтительно), SVG (через `svg-inkscape`) |
| Цвета | Только grayscale |
| Заливки и подложки | 10–80% K |
| Толщина линий | min 0.25 pt |
| Шрифты в графике | Те же, что и в основном тексте, embedded |

## Шрифты

| Параметр | Значение |
| --- | --- |
| Лицензия | Только свободные или с правом коммерческой публикации |
| Embed | Все начертания, все используемые, subset |
| Кириллица | Полный набор: regular, italic, bold, bold italic |
| Smallcaps | Настоящие (если шрифт имеет), не псевдо-капитель |
| Старостильные цифры | Для основного текста по возможности |
| Табличные цифры | Для таблиц |

Дефолт серии: **PT Serif** (основной), **PT Sans** (sans),
**JetBrains Mono** (моноширинный). Все три — бесплатные с
кириллицей и правом коммерческого использования.

## Корешок

| Параметр | Расчёт |
| --- | --- |
| Толщина корешка | Считает типография по плотности и числу страниц |
| Формула приблизительно | `толщина = страницы × плотность × 0.001 мм` |
| Пример | 200 стр., 80 г/м²: ~16 мм корешок |

Текст на корешке (для книг толще ~6 мм):
- Снизу вверх — европейская традиция
- Сверху вниз — англо-американская
- Россия — обе допустимы, выбрать одну для серии

## Бумага

| Параметр | Рекомендация |
| --- | --- |
| Плотность блока | 70–80 г/м² для большинства тиражей |
| Оттенок | Кремовый (легче для глаз) или белый (дешевле) |
| Тип | Офсет, не газетная |
| Pulp | Не имеет значения, кроме как для долговечности |

## Обложка

| Параметр | Значение |
| --- | --- |
| Плотность | 250–300 г/м² (мягкая обложка) или картон 2 мм + переплётный материал (твёрдая) |
| Ламинирование | Матовое (не царапается), глянцевое (дешевле), soft-touch (премиум) |
| Цвет | Допустимо цветную обложку при ч/б блоке — это нормально и распространено |
| Формат | Trim 148×210 + корешок + 5 мм с каждой стороны под загиб |

Обложка верстается отдельным PDF, отдельным процессом — это не
зона ответственности book-template на данном этапе.

## Pre-print proof

**Обязательно** перед запуском тиража:

1. Типография печатает один сигнальный экземпляр на той же бумаге,
   тем же станком, как и тираж
2. Автор вычитывает физический экземпляр (минимум 24 часа):
   - Качество печати: не плывёт ли текст, чёткость листингов и QR
   - Чёткость линий и схем
   - Цветопередача (для ч/б — равномерность серого)
   - Корешок: не уходит ли текст в переплёт
   - Скан QR-кодов на нескольких страницах
3. При проблемах — правка PDF и повторный proof

Без сигнального экземпляра в тираж не запускать никогда.

## Команда сборки

```bash
./book.sh build print
```

Результат — `build/<slug>-print.pdf` в Device Gray, PDF/X-1a,
готовый к отправке в типографию.

Проверка перед отправкой:

```bash
verapdf --flavour 1a build/<slug>-print.pdf
gs -o - -sDEVICE=inkcov build/<slug>-print.pdf | tail -20
# должно показывать только K, без CMY
```

## Список того, что выяснять у типографии

При выборе типографии:

- [ ] Минимальный и оптимальный тираж
- [ ] Принимаемый ICC-профиль (FOGRA39? свой?)
- [ ] Принимаемые PDF-стандарты (X-1a? X-3? X-4?)
- [ ] Допуски на обрез (±1 мм? ±2 мм?)
- [ ] Тип переплёта в их матрице (КБС / шитьё)
- [ ] Доступные плотности бумаги
- [ ] Оттенки бумаги в наличии
- [ ] Срок изготовления и логистика
- [ ] Pre-print proof: входит в стоимость или отдельно
- [ ] Цена за экземпляр в нашем тираже
- [ ] Можно ли получить spec-sheet или техническое задание
  для финальной проверки
