# Русская типографика: правила набора

Этот документ задаёт правила русского набора, которые применяются
автоматически препроцессором (`theme/filters/russian-typo.py`)
ко всем форматам.

Часть правил автор соблюдает руками — препроцессор не может
их вывести из текста. Эти случаи помечены [руками].

## Знаки препинания и пунктуация

### Кавычки

- **Внешние «ёлочки»** для прямой речи и цитат:
  ```
  Источник: "это представление"  →  Источник: «это представление»
  ```
- **Вложенные „лапки"** внутри ёлочек:
  ```
  «План — это „представление" движка»
  ```
- В тексте на английском внутри русского текста — английские кавычки `"..."`

### Тире vs дефис vs минус

- **Длинное тире `—` (em-dash)** для разрыва мысли, перечислений
  с пояснением, между подлежащим и сказуемым:
  ```
  План запроса -- это дерево     →   План запроса — это дерево
  ```
- **Короткое тире `–` (en-dash)** для диапазонов:
  ```
  главы 3-5                       →   главы 3–5
  ```
- **Дефис `-`** в составных словах и переносах:
  ```
  бизнес-логика, кто-то
  ```
- Препроцессор: `--` → `—`, `<digits>-<digits>` → `<digits>–<digits>`,
  обычный дефис в словах не трогает.

### Многоточие

- Один символ `…`, не три точки подряд:
  ```
  и так далее...                  →   и так далее…
  ```

## Пробелы

### Неразрывный пробел (`~` в LaTeX, `\u00A0` в HTML)

**Висячие предлоги и союзы** — не остаются в конце строки:

```
В таблице количество              →   В~таблице количество
По регистру накопления             →   По~регистру накопления
И так далее                        →   И~так далее
```

Однобуквенные и двухбуквенные предлоги/союзы:
`в, во, и, к, ко, на, не, о, об, от, по, с, со, у, а, но, да,
же, ли, бы, что, как, то`.

**Между числом и единицей измерения:**

```
5 мм          →   5~мм
100 страниц   →   100~страниц
```

**В инициалах:**

```
А. С. Пушкин   →   А.~С.~Пушкин
```

**В сокращениях:**

```
т. е., и т. д., и т. п., т. к., см. рис.   →
т.~е., и~т.~д., и~т.~п., т.~к., см.~рис.
```

**Перед знаком §:**

```
параграф 7.1   →   параграф~7.1
§ 7.1           →   §~7.1
```

### Разряды чисел

Большие числа разделяются **тонким пробелом**, не запятой и
не обычным пробелом:

```
100000              →   100\,000
1500000             →   1\,500\,000
```

В LaTeX `\,` даёт `\thinspace`. В HTML — `<span class="thin">` или
прямой `\u2009` (тонкий пробел).

Препроцессор: только для чисел в обычном тексте, **не в коде** и
**не в URL**.

### Французский интервал

Двойной пробел после точки — **не нужен**, всегда одинарный.
LaTeX по умолчанию ставит двойной, отключаем через `\frenchspacing`.

## Знаки и символы

### Знак умножения

- `×` (U+00D7), не латинская x:
  ```
  148 x 210 мм   →   148×210~мм
  ```

### Знак градуса и температура

```
25°C            →   25\,°C    или   25~°C
```

### Проценты и валюта

```
50%             →   50\,%       (тонкий пробел перед %)
1000 руб.       →   1000~руб.
```

## Структура и выделения

### Заголовки

- Без точки в конце:
  ```
  ## Зачем читать данные.   →   ## Зачем читать данные
  ```
- Без жирности и курсива внутри (это уже задано стилем
  заголовка)

### Выделения в тексте

- **Жирный** — для определений и ключевых терминов при их
  первом упоминании
- *Курсив* — для новых понятий, иностранных слов, акцента
- `Моноширинный` — для кода, имён файлов, технических терминов
- Не использовать **жирный курсив** одновременно
- Не использовать ПОДЧЁРКИВАНИЕ — это типографически плохо

### Перечисления

- В нумерованных списках используется арабская нумерация;
  римская — только в исключительных случаях
- Перед двоеточием, открывающим список, **не должно** быть точки:
  ```
  Принципы:                       НЕ:  Принципы.
  - первый                              - Первый
  - второй                              - Второй
  ```

## Перенос слов

Полагаемся на автоматические переносы polyglossia (`russian`).
Запрещаем перенос в:

- Аббревиатурах: `ОПОП`, `СНГ` — не разрывать
- Числах с единицами: `100~мм` — неразрывный пробел сам решит
- Между знаком % и числом

## Не делать [руками]

Препроцессор не может вывести из контекста, но автор должен
помнить:

- **Не разделять имя и отчество** переносом строки
- **Не разделять название и номер** (Глава~3, рис.~7.1, §~7.1) —
  всегда через `~`
- **Не оставлять союз/предлог в конце строки** — препроцессор
  пытается, но в спорных случаях ставь `~` вручную
- **Не злоупотреблять заглавными буквами** внутри предложения
- **Не использовать ALL CAPS** для выделения

## Источники

Правила основаны на:

- Мильчин А.Э., «Справочник издателя и автора» — основной канон
  русского книжного набора
- Артемий Лебедев, «Ководство» — современная типографика
- ГОСТ 7.36-2006 — для академических изданий
- Adobe Russian Typesetting Guide — для micro-typography

## Применение

Препроцессор `theme/filters/russian-typo.py` применяется ко всем
форматам по умолчанию для книг с `lang: ru` в `metadata.yaml`.

Отключается через `metadata.yaml`:

```yaml
typography:
  russian_preprocessor: false
```

Игнор для конкретного фрагмента:

```markdown
::: no-typo
"кавычки" не меняются, --- не превращаются в тире
:::
```
