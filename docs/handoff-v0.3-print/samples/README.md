# samples/

Референсные образцы вёрстки для проверки соответствия
реализации спецификации.

## A5-sample-v4-qr.pdf

4 страницы A5 ч/б, собранные в session:

- **Стр. 1** — оглавление в стиле серии
- **Стр. 2** — спуск полосы главы 7, эпиграф, буквица, QR на git-tree главы
- **Стр. 3** — полоса с листингом, QR на raw-файл, врезка «На полях»
- **Стр. 4** — TikZ-схема дерева операций, врезка «Определение»,
  контрольные вопросы

При сборке через `./book.sh build print` ожидаемо получить
вёрстку **стилистически соответствующую** этому референсу
(шрифты, начертания, расстояния, типы врезок, формат подсветки).

Это не значит «бит-в-бит», но это значит:
- Те же типы линеек у врезок
- Та же подсветка кода (жирность для keywords)
- Те же колонтитулы (twoside: глава слева, параграф справа)
- Тот же стиль эпиграфов
- Те же QR в тех же местах

## Пересборка референса (для разработки template)

Образец собран из преамбулы, описанной в `theme/print.tex`,
плюс TikZ-схема и QR-обёртки.

Если нужно пересобрать (например, для проверки изменений
в стилях):

```bash
# 1. Положить onec_lexer.py и pygstyle-bw.tex в рабочий каталог
# 2. Положить листинг в файл listing01.1cq
# 3. Сгенерировать подсветку:
pygmentize -l onec_lexer.py:OneCLexer -x -f latex \
  -O style=bw,commandprefix=PYone -o listing01.tex listing01.1cq

# 4. Положить sample.tex (см. артефакты сессии)
# 5. Собрать:
xelatex -interaction=nonstopmode sample.tex
xelatex -interaction=nonstopmode sample.tex
```

## Когда обновлять референс

- При изменении `theme/print.tex` так, что меняется визуальный
  стиль (новый шрифт, изменение разметки, новый тип врезки)
- При выходе минорной версии шаблона (документировать в CHANGELOG)
- При уточнении спецификации печатного издания

Старые версии референса сохранять в `samples/archive/` для
возможности сравнения.
