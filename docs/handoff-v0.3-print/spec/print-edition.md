# Печатное издание серии «Школа 1С-инженеров»

Этот документ — SDD-слой для расширения `book-template` поддержкой
print-ready PDF под малотиражную офсетную ч/б печать.

## ЭТО ЕСТЬ

- **Малотиражный офсет** (200–2000 экземпляров) формата A5 (148×210 мм)
- **Ч/б печать (1 канал K)**, не RGB→grayscale, не дуплекс
- **Различение синтаксиса** через начертание (жирность, курсив),
  не через цвет
- **Векторная графика**: схемы в TikZ, QR в qrcode-package, без растра
  там, где это возможно
- **Версионируемые QR-ссылки** на git-теги, а не на main
- **Аппарат учебника**: титул, оборот титула с ISBN/УДК/ББК/копирайтом,
  оглавление, шмуцтитулы частей, эпиграфы, врезки (Определение,
  На полях, Пример, Контрольные вопросы), предметный указатель,
  выпускные данные
- **Twoside-вёрстка**: чётная страница — название главы в колонтитуле,
  нечётная — название параграфа; на спуске колонтитула нет
- **Pre-press-готовый PDF/X-1a** с embed шрифтами и Grayscale ICC-профилем
- **Pandoc-template поверх memoir**, не свой класс с нуля

## ЭТО НЕ ЕСТЬ

- Не цветная печать (другая ценовая категория, не для малотиражного офсета)
- Не fixed-layout (параллельно с PDF собираются EPUB/HTML/DOCX из того же
  Markdown, поэтому исходник остаётся reflowable)
- Не «красивая вёрстка ради красоты» — каждое решение оправдано
  офсетной экономикой или читаемостью
- Не дублирование ручных работ (типографы, корректоры): pipeline
  собирает print-ready PDF одной командой
- Не зависимость от платных шрифтов или коммерческих LaTeX-пакетов
- Не замена Markdown как формата исходника — Markdown остаётся истиной

## Метрики успеха

| Метрика | Цель |
| --- | --- |
| Сборка print-PDF | `./book.sh build print` без warnings |
| Валидация PDF/X-1a | `verapdf` проходит |
| Цветовое пространство | Только Device Gray в финальном PDF |
| Embed шрифтов | Все начертания subset-embedded |
| Соответствие референсу | Сравнение полосы с `samples/A5-sample-v4-qr.pdf` |
| Не сломать другие форматы | EPUB/FB2/HTML/DOCX собираются как раньше |
| Прохождение на живом тексте | Две готовые книги «1С как иностранный язык» собираются без правок текста |
| Время сборки | Локально <2 мин на книгу 200 страниц, CI <5 мин |

## Принципы (SDD-уровень)

1. **Один Markdown — много форматов.** Любая фича, добавляемая
   в Markdown-разметку, должна иметь стратегию рендера в каждом
   из 6 форматов: print-PDF, electronic-PDF, EPUB, FB2, HTML, DOCX.
   Стратегия может быть «fallback на простой текст», но должна
   быть явной.

2. **Конфиг через `metadata.yaml`, не через хардкод.** Все
   книгоспецифичные параметры (ISBN, тег QR, поля, переплёт,
   ICC-профиль) живут в YAML, не в LaTeX-коде.

3. **Книгоспецифичное локально, общее в template.** В книгу
   попадают только её собственные данные. Стили, лексеры,
   filters, врезки — в `theme/`, обновляются sync-механикой.

4. **SDD перед кодом.** Любая новая возможность сначала
   описывается в spec, потом реализуется.

5. **Семантическая разметка важнее презентационной.**
   Markdown пишется в терминах смысла («Определение»,
   «На полях», «Контрольный вопрос»), не оформления.
   Презентация — в theme.

6. **Версионируемая воспроизводимость.** Сборка фиксированной
   версии книги должна давать байт-идентичный PDF при том же
   состоянии репозиториев `book-template` и книги.

## Архитектурные решения, зафиксированные

| ADR | Решение | Альтернативы (отвергнуты) |
| --- | --- | --- |
| 001 | Memoir-класс под капотом | KOMA-Script (scrbook), classicthesis, tufte-book |
| 002 | Pandoc-template, не свой `.cls` | Свой класс LaTeX с нуля |
| 003 | XeLaTeX для сборки | LuaLaTeX (можно перейти при необходимости TeX-Lua скриптинга) |
| 004 | Pygments+bw-стиль для подсветки | Listings (плохо с кириллицей), minted (не поддерживает customlexer через tcolorbox), ручная разметка |
| 005 | Кастомный 1С-лексер (Python) | SQL-лексер (не понимает русские keywords), без подсветки |
| 006 | Fenced divs для врезок | Шорткоды, кастомные XML-теги |
| 007 | TikZ для схем | Mermaid, Graphviz, draw.io+SVG, ручной рисунок |
| 008 | qrcode-package для QR | qrencode→PNG (растровый), внешняя генерация |
| 009 | Ч/б через bold/italic, не серый | Серая шкала (хуже на офсете), цвет (дорого в печати) |
| 010 | Twoside-вёрстка с openany | Oneside (теряет навигацию), openright (vacat-страницы в образце) |

## Открытые вопросы

- Сохранять ли FB2 для технических книг? (Эрзац-врезки выглядят бедно.)
  Решение отложено до прогона на «Семантике».
- Маргиналии на A5 — закладывать или нет? (Поле 14 мм узковато.)
  Решение отложено до прогона на «Семантике».
- ICC-профиль — generic Coated FOGRA39 или специфичный?
  Зависит от типографии — выбор отложен.
- Скриншоты UI 1С — формальные права. До решения — TikZ-mockups.
- Шрифт основного текста: остаёмся на PT Serif (из metadata.yaml)
  или переходим на Lora / Source Serif Pro? Решение по результатам
  прогона на «Семантике».
